# Street Eats Food Truck Website

A modern, responsive website for a food truck business featuring vibrant graphics, smooth animations, and an engaging user experience.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Animated Graphics**: Includes a custom-built food truck graphic with animations
- **Interactive Menu**: Showcases menu items with hover effects and pricing
- **Location Schedule**: Weekly schedule showing where to find the food truck
- **Contact Form**: Easy-to-use contact form for inquiries
- **Smooth Scrolling**: Navigation with smooth scroll effects
- **Easter Egg**: Click the truck icon 5 times for a special surprise!

## How to Use

1. Open `index.html` in any modern web browser
2. Navigate through different sections using the navigation menu
3. View the menu, schedule, and contact information
4. Submit inquiries through the contact form

## Sections

- **Home**: Eye-catching hero section with food truck graphic
- **Menu**: Display of menu items with prices
- **About**: Business information and statistics
- **Location**: Weekly schedule of locations
- **Contact**: Contact information and inquiry form

## Customization

### Update Business Information

Edit the HTML content in `index.html`:
- Change business name in the navigation logo
- Update menu items and prices
- Modify location schedule
- Update contact information

### Customize Colors

Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #FF6B35;
    --secondary-color: #F7931E;
    --dark-color: #2C3E50;
    --light-color: #ECF0F1;
}
```

### Add Features

The `script.js` file contains all interactive functionality. You can:
- Modify the contact form behavior
- Add new animations
- Customize scroll effects
- Add more interactive elements

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (no frameworks required)

## Browser Support

Works on all modern browsers:
- Chrome
- Firefox
- Safari
- Edge

## Tips

- The website is fully self-contained with no external dependencies
- All graphics are CSS-based for fast loading
- The design uses a vibrant color scheme perfect for food businesses
- Mobile-responsive design ensures great experience on all devices
